## About

**Moring**은 자유롭고 진실된 소통을 시작으로,
사용자의 일상과 정보, AI, 개발자 도구를 하나의 생태계로 연결합니다.

각 서비스는 독립적으로 사용할 수 있으며,
**Moring Account**를 중심으로 하나의 경험으로 연결됩니다.

---

## Core

### [Moring](https://moring.co/)

Moring 생태계의 중심이 되는 소셜 네트워크 플랫폼.

### [Moring Account](https://account.moring.co/)

Moring 서비스 전체에서 사용하는 통합 계정 및 로그인 시스템.

### [Moring Developers](https://developers.moring.co/)

OAuth 앱 등록, API 키 발급 및 외부 서비스 확장을 위한 개발자 플랫폼.

---

## Products

### [Mordy](https://mordy.moring.co/)

공부와 집중을 위한 온라인 학습 서비스.

### Morit

링크·메모·미디어·활동 기록을 저장하고, 이를 기반으로 개인형 AI가 활용하는 개인 정보 허브.

### [Mori](https://mori.moring.co/)

Moring 생태계의 서비스와 정보를 연결하기 위해 개발된 AI 시스템.
