## 소개

Moring은 자유롭고 진실된 소통을 추구합니다!

## 서비스 목록

* [Moring SNS](https://moring.co/) – Moring 중심부, 소셜 네트워크 플랫폼
* [Mordy](https://mordy.moring.co/) – 온라인 스터디룸
* [Moring Account](https://account.moring.co/) – Moring 계정 관리

## 실험 기능
* [Mori AI](https://mori.moring.co/) - Moring 생태계 핵심 자산이 될 AI 에이전트
* [Mordy Flight](https://lab.mordy.moring.co/) - 컨셉을 비행으로 한 Mordy 실험 기능
* [Moring Developers](https://developers.moring.co) - 외부 서비스 확장을 위한 OAuth 연동, API 키 발급 등을 담당
